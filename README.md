# Agenda Telefónica

Microservicio REST desarrollado con Java y Spring Boot para gestionar contactos de una agenda telefónica.

El servicio permite crear, consultar, listar, actualizar y eliminar contactos mediante borrado lógico.

## Tecnologías

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- Lombok

## Ejecutar el proyecto

Desde la raíz del proyecto:

- Hacer Clic derecho en el archivo `pom.xml`y agregar a mvn project.
- En las herramientas de mvn del lado derecho, despejar el proyecto y en `lifecycle`hacer doble clic en *clean* y luego doble clic en *install*.
- Por ultimo ejecutar el proyecto.
- Agregar la coleccion de postman que se encuentra en la carpeta `Evidencias`
